# 核心時序與驗證邊界

GameCore不依賴DOM、網路、資料庫，60Hz固定tick。skills.ts是唯一25技能來源，網站圖鑑／選技／預警／AI／核心使用同表。numeric-v2不得暗改。

步序：到期清理（物件、護盾、定身／失衡期限）→每標籤重武裝及安全逾時→一次性輸入嘗試→主動／強制位移、精確常加速度跳躍、地面分離→到期準備生成→相對運動掃掠及早接觸→按交會時間／施法開始tick／ID／段結算→全部目標死亡→時間到→發布。開始tick+N生成，窗口[生成tick,生成tick+N)，冷卻到期tick可重新開始。氣量每格120，回氣每步1，格擋每施法目標首次60。

InputRouter按每個一次性label離開時間重武裝6tick；A→B不延後已武裝B。非法輸入先在伺服器拒絕，不得更新活性。非法施法仍算一次嘗試，不排隊。倒數／暫停不推進tick，開始要求NONE，再等待6步，不偷放。

跳躍用y+=vy*dt+0.5*g*dt²，vy+=g*dt， apex676/flight48tick。掃掠採相對移動圓對矩形的圓角邊／角quadratic，矩形採slab，嚴格正面積；不把圓外接矩形當命中。掃掠的角色運動在單步內以兩端連線近似，與解析跳躍端點一致。每step角色站／蹲框由當下姿態決定。

護盾、根控制、僵直、失衡、收招與免疫分開。格擋不與不屈相乘；先減傷、護盾再生命，保留兩位小數。一次施法多段首次格擋扣氣與停頓，同步歸零後後續段失衡不得再格擋。反射保留施法ID／剩餘寿命／路程，僅反vx，不重反。控制共享互斥與結束後2秒免疫；一般僵直0.2秒且結束後0.3秒免疫。

PVE過關以結算后存活為前提，獎勵仅defeat一次；清效果、失衡及物件，保留剩餘cooldown和累計20秒，tick不在間歇倒數下降。敵人每關新elapsed0，配置固定表序；seed保存，AI延遲讀公開歷史，不接收玩家隱藏大招。AI不直接寫位置／傷害，送InputRouter，反應概率每施法抽一次。

server accumulator保留實際落後時間，每輪有界10次補步，過載累計lag。健康資訊記錄 p95、步數、記憶體及 snapshot bytes。資源容量可配置，活動機器容量需依實際並行需求評估。
